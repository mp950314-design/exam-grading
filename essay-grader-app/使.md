# 申論題批改台

三等刑事警察人員特考申論題批改工具。輸入科目、題目、擬答，取得五個維度的給分＋逐段評註，並存進 Supabase 累積歷史紀錄與各科趨勢。

## 設定步驟

1. 安裝套件
   ```
   npm install
   ```

2. 建立 `.env`（複製 `.env.example` 改名）並填入：
   - `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY`：沿用 FDS 同一個 Supabase 專案的值（Supabase 後台 → Project Settings → API）
   - `VITE_ANTHROPIC_API_KEY`：你的 Anthropic API key

3. 在 Supabase 後台的 SQL Editor 執行 `supabase/schema.sql`，建立 `essay_gradings` 資料表（跟 FDS 現有的表分開，不會互相影響）。

4. 啟動開發伺服器
   ```
   npm run dev
   ```

## 重要提醒

- `VITE_ANTHROPIC_API_KEY` 會被打包進前端程式碼、在瀏覽器端直接呼叫 Anthropic API。這樣做只適合你自己本機開發用；**不要把 build 出來的網站部署到公開網址**，否則等於把 API key 公開給所有訪客。之後如果想公開部署，要改成透過後端（例如簡單的 serverless function）代呼叫 API。
- `supabase/schema.sql` 目前的 RLS policy 是全開（任何人拿 anon key 都能讀寫這張表），這在本機個人使用沒問題；如果之後要多人使用或公開部署，記得改成有身份驗證的 policy。

## 之後可以擴充的方向

- 科目的批改重點（常考法條、鑑識流程重點）目前寫在 `src/lib/grader.ts` 的 system prompt 裡，之後想針對不同科目給更精準的批改標準，可以把它拆成 per-subject 設定檔。
- 目前只有「各科目平均分數」的簡單趨勢，之後想看時間趨勢圖可以在歷史紀錄頁加上折線圖（例如用 recharts）。
- 等你手上有官方參考答案或評分標準後，可以在批改時把它一併傳給模型，要求模型明確標注跟參考答案的差異，取代目前純靠模型自身判斷的方式。
